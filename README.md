# 장사의신 — 국내 P1 통합 시제품

## 실행 환경
- 기준 엔진 버전: Godot 4.7.2 Standard (`4.7.2.stable.official.ed1daf0bf`), GDScript, Compatibility 렌더러.
- Godot 프로젝트 관리자에서 이 저장소의 `project.godot`를 가져오거나 열고 F5를 눌러 실행합니다. 현재 main 장면은 야외 지도입니다.

## 이용 흐름
- 서울/인천 야외에서 시청에 들어가 시장을 이용합니다. 상품·매매·인물·수량을 선택하고 법인 잔액·총액·중량을 확인한 뒤 확정 또는 취소합니다.
- 사옥에 진입하면 대표 책상 시점의 실내가 열립니다. 노트북·전화기·비서 그림 위에 포인터를 올리면 세이지색 외곽선과 부드러운 광이 강조되고 대상 안내가 바뀝니다. 클릭하면 해당 대상의 선택 메뉴가 열립니다. 노트북은 조사·보고·뉴스·재무, 전화기는 직원 연락 상태 확인, 비서는 직원 상태에 따른 동행 합류/출장 취소를 제공합니다. 회의와 야외 복귀는 우측 상단 버튼입니다.
- 동행 인물은 좌측 세로 초상 슬롯에 최대 4명까지 표시합니다. 현재 이동 대표는 주인공 1명이며 초기 직원 1명을 함께 표시하고 나머지는 빈 슬롯으로 남습니다. 날짜·계좌·차량·납부 상태는 좌측 하단 패널로 옮겼고 화면 아래 조작 안내는 중앙에 배치했습니다.
- 야외 이동은 지면 클릭 또는 키보드 방향키만 사용합니다. WASD 이동은 없습니다. 사옥·시청 건물 위에는 방문 표식이 표시되며, 건물 그림 위에 포인터를 올리면 금색 강조와 손 커서가 나타납니다. 건물 또는 방문 표식을 클릭하면 주인공이 출입구 앞으로 걸어가고 도착 후 상호작용 메뉴가 열립니다. 메뉴의 내부 보기/취소를 선택합니다. UI 위 클릭은 이동 명령이 되지 않습니다.
- 건물 상호작용 디버그: F5 실행 후 하단 **출력(Output)** 패널에서 `[BUILDING_INTERACTION]`을 확인합니다. 클릭부터 메뉴 오픈까지 단계가 기록됩니다. 건물 하나를 클릭한 뒤 이 접두어가 붙은 줄을 복사해 전달하면 끊긴 지점을 확인할 수 있습니다.
- 인물별 적재 한도는 20kg입니다. 초기 직원은 주인공과 동행하지만, 조사 출장 전 직원이 가진 화물을 주인공에게 옮기고 동행 해제를 확인해야 합니다.
- 서울·인천은 하나의 야외 지도에서 다리로 연결됩니다. 지역 버튼은 상대 도시 시청까지 걷는 명령이며 순간 전환하지 않습니다. 기준 경로 환산 거리 30,000m는 유지하고 사용자의 이동속도 조정 요청에 따라 현재 도보 편도 목표를 약 22.5초(기존 45초의 약 2배 속도)로 설정했습니다. 도로·다리·강·건물 경계를 같은 내비게이션/충돌 데이터에 맞췄습니다. 방향키 또는 클릭으로 이동합니다. 차량을 보유·선택하면 실제 이동 거리에 따라 법인계좌에서 운송비가 차감되고 속도 및 적재량이 바뀝니다. 경로 순찰 적은 강을 건너는 다리에서 출현하도록 구성했습니다.
- 차량은 사옥의 노트북 메뉴에서 구매·선택합니다. 시청 시장 화면에서 인물 또는 활성 차량을 화물 주인으로 선택하고, 같은 위치의 차량 화물 이전·현지 임시 보관·재회수를 할 수 있습니다. 운송비 부족으로 차량이 주차되면 표식 근처에서 회수할 수 있으며, 차량 화물은 자동으로 인물에게 옮겨지지 않습니다.
- 적 접촉 시 수동 전투 화면으로 전환됩니다. 일반 공격·고유기·방어·교체·도주를 직접 선택합니다. 승리·도주·패배 결과는 저장 ID로 한 번만 정산됩니다. 패배하면 회사 전화와 직원 협상으로 진행하며, 요구액 부족분은 석방 전용 구조 채무가 됩니다. 구조 채무는 월 납부일에 3회 분할 상환하도록 기록됩니다.
- 게임 날짜는 야외와 사옥에서만 진행하며 활성 플레이 600초마다 월 기념일로 이동합니다. 2025-01-20에서 시작하고, 시청·재무·업무 패널·뉴스 확인 중에는 정지합니다.
- 사옥의 `시장 조사 지시`에서 서울 또는 인천을 선택합니다. 출장비 5,000원과 기간 2게임일이 법인 계좌에서 처리됩니다. 취소해도 출장비는 환불되지 않습니다. 직원 화물은 출장 전 비워야 합니다.
- `조사 보고`는 도착 시점의 시장 재고·관측 가격·관측일·최근 관측 가격 추세를 보여주는 고정 스냅샷입니다. 현재 시세로 자동 갱신되지 않습니다.
- 수원·천안 시청에서도 각 지역 시장을 이용할 수 있습니다. 두 지역은 서울과 같은 육상 지도에 연결되고 지역별 상품 취급·가격 계수·작업장 수당을 사용합니다.
- 시청의 `작업장`에서 같은 패 두 개를 가로·세로로 연결해 제거합니다. 꺾임은 최대 2회이며 막힌 패를 통과할 수 없습니다. 제한시간은 세계 달력과 별도로 흐르고, 성공 수당은 개인 계좌로 한 번만 지급됩니다. 실패·포기는 보상 없이 끝나며 피로도는 게임 날짜가 바뀔 때 회복됩니다.
- 보드에서 패 두 개를 차례로 클릭해 제거하고, `힌트`는 한 판에 1회, `포기`는 보상 없이 작업장을 종료합니다. 해금되지 않은 난도는 선택할 수 없습니다.
- 사옥에서 계좌·원장·출자·허용된 원금 반환 및 실현이익 인출을 확인할 수 있습니다. 월세 100,000원과 초기 직원 급여 80,000원은 매월 계약 기념일에 법인계좌에서 청구됩니다.
- 사옥 재무에서 임대 확장·자가 사옥 구입·직원 고용/역할·일반 대출을 확인할 수 있습니다. 확장 임대는 월 250,000원, 이동 비용 200,000원, 정원 4명이며 자가 사옥은 12,000,000원, 관리비 월 100,000원, 정원 6명입니다. 직원 급여는 1인당 월 80,000원입니다. 일반 대출 한도·이자·상환은 기획 수치로 계산하며 피랍 석방 전용 구조 채무와 별도 기록합니다.
- 선택된 연체 정책은 월 이자·구조 채무 납부 부족액의 수수료 없는 이월, 대출 완납 전 담보 자가 사옥 매각 차단, 현금 부족 시 게임오버 대신 영업 지속입니다. 실제 자산 처분은 매각가가 기획에 정의되지 않아 아직 제공하지 않습니다.
- 설정은 `user://settings.cfg`에 저장되어 게임 세이브와 분리됩니다. 진행 상태는 기존 `user://saves/phase1_save.json` 경로를 유지하며 현재 저장 스키마는 5입니다. schema 1~4 저장을 보완 변환하고 사용자 세이브를 삭제하지 않습니다.
- 게임 내 가상 뉴스는 2025-02-01 전자부품 공급 감소, 2025-03-01 생활잡화 수요 감소 시나리오입니다. 기사 확인 후 거래가 재개되고, 사옥의 기사 보관함에서 다시 읽을 수 있습니다.

## 저장과 검사
- 기존 `user://saves/phase1_save.json` 경로를 유지합니다. 기존 schema 1~4 저장은 위치·계좌·화물·시장·달력·조사·차량·전투·피랍 상태를 보존하고 Phase 5 사무실·대출·작업장 상태의 기본값을 채워 schema 5로 보완합니다. 세이브를 삭제하지 않으며 자동 백업은 `.bak`에 둡니다. 설정 파일만 별도입니다.
- 검사 전용 appdata를 프로젝트 캐시 아래에 두고 실행합니다. 검사 코드가 `user://phase3_checks/` 또는 `user://phase2_checks/`를 사용하며 기본 저장과 분리합니다.
  ```powershell
  $env:APPDATA = Join-Path (Get-Location) '.godot\phase_test_appdata'
  # Godot 콘솔 실행 파일이 PATH에 있으면 아래 명령을 사용합니다.
  $godot = (Get-Command godot_console.exe -ErrorAction Stop).Source
  & $godot --headless --path . res://tests/phase2_checks.tscn -- --phase2-tests
  & $godot --headless --path . res://tests/phase3_checks.tscn -- --phase3-tests
  & $godot --headless --path . res://tests/phase4_checks.tscn -- --phase4-tests
  & $godot --headless --path . res://tests/phase4_checks.tscn -- --phase4-tests --phase4-reload
  & $godot --headless --path . res://tests/phase5_checks.tscn -- --phase5-tests
  & $godot --headless --path . res://tests/phase5_checks.tscn -- --phase5-tests --phase5-reload
  & $godot --headless --path . -- --phase5-map-tests
  ```
- 위 명령은 `APPDATA`를 프로젝트 `.godot/` 아래 별도 경로로 먼저 설정해 사용자 저장과 분리해 실행합니다. 정상 결과는 Phase 2 `PHASE2_CHECKS_OK: 9 groups`, Phase 3 `PHASE3_CHECKS_OK: 6 groups`, Phase 4 `PHASE4_OK`/`PHASE4_RESTART_OK`, Phase 5 `PHASE5_OK`/`PHASE5_RESTART_OK`, 지도 `PHASE5_MAP_OK`입니다. P0 전체 통합·재시작은 아래 “P0 통합 검사” 명령을 사용합니다.

## Windows 내보내기
Godot 4.7.2에서 Windows Desktop preset을 추가하고, 같은 버전 템플릿을 준비한 뒤 출력 경로를 `builds/windows/`로 지정합니다. 확인된 템플릿은 `%APPDATA%\Godot\export_templates\4.4.1.stable.mono`뿐이며 기준 엔진과 버전/렌더링 형식이 맞지 않습니다. 다운로드·설치 승인 없이 진행하지 않았으므로 Windows 출력 생성과 실행 검증은 미실행입니다.

## 임시 자산과 미구현 기능
- `assets/protagonist_8dir_sheet.png`는 실제 알파 투명 배경 4×2의 SD 미니 주인공 8방향 시트입니다. 1행은 북·북동·동·남동, 2행은 남·남서·서·북서 정지 포즈입니다. 걷기 프레임 애니메이션은 없습니다. 셀 크기는 텍스처 실측 크기에서 계산합니다.
- `assets/staff_01_portrait.png`는 실제 알파 투명 배경의 초기 직원 1 SD 미니 초상이며 왼쪽 동행 슬롯에 연결했습니다. 직원의 야외 이동 스프라이트는 만들지 않았습니다.
- `assets/party_roster_plaque.png`는 이번 UI 개편에서 생성한 투명 배경의 4칸 세로 초상 프레임입니다. 플레이어·동행 직원 초상은 기존 이미지가 슬롯 안에 올라가며, 생성 이미지는 임시 자산이므로 최종 UI 원화는 아닙니다.
- `assets/ui_skin_sheet.png`는 이전 RGB 체크무늬가 그림에 포함돼 현재 사용하지 않습니다. 초상 테두리는 장면의 둥근 StyleBox로 표시하고 UI 색은 `game/ui/game_theme.tres`에서 적용합니다.
- `assets/office_seoul_interior_bg.png`는 서울타워·한강·서울 시가지를 창밖에 크게 담은 사옥 내부 임시 배경입니다. 기존 책상·노트북·비서·전화 구도는 유지해 `game/office/office.tscn`의 클릭 영역과 맞췄습니다. 업무 메뉴는 별도 UI로 표시하며 기존 조사·보고·뉴스·재무·전화·회의·나가기 동작을 유지합니다. 이전 배경 `assets/office_interior_bg.png`는 교체 참고용으로 보존했습니다.
- `assets/seoul_office.png`, `assets/seoul_city_hall.png`, `assets/incheon_city_hall.png`는 실제 알파 투명 배경의 귀여운 2D SD 일러스트풍 건물 외관입니다. 야외 지도에는 공원 수목·도심 실루엣·한강 다리·인천 항만 장식을 두었습니다. NavigationRegion2D·NavigationAgent2D로 강과 건물 외곽을 우회하며 강은 다리에서만 건널 수 있습니다. 도시 장식 실루엣과 수목은 충돌 없는 배경입니다.
- 위 그림은 프로젝트용 임시 생성 에셋입니다. UI 기능과 별개로 최종 미술·일관된 애니메이션·에셋별 사용권 검토는 남아 있습니다.
- 적은 현재 서울↔인천의 다리 순찰 1개와 초급 조우만 배치했습니다. 일반 적 그룹의 야외 배치·적 출현 빈도/전수 밸런스·전투 중 효과 및 모든 GUI 상호작용은 추가 점검이 필요합니다. 차량·전투·피랍 관련 화면 아이콘/연출은 기능 임시 UI와 도형 표식이며 최종 미술이 아닙니다.
- 차량·전투·피랍·국내 작업장·수도권 4개 지역·초기 사옥 성장/일반 대출까지 P1 국내 범위에 포함합니다. 직원 원격 매매·주식·해외·P2 항해는 구현하지 않았습니다. 담보 자산 처분 가격과 현금 위기 시 처분 대상 선택 화면은 미정/미구현입니다.

### 사옥 실내 개선 검토 및 에셋 목록
- 현재 사옥 기능은 있으나 기존 화면은 단색 배경에 조사·전화·회의·재무 버튼을 한 목록으로 배치해 공간과 조작 위치가 드러나지 않았습니다. 대표실 배경, 물체 hover 강조, 오브젝트 선택 메뉴, 상시 보이는 회의/나가기 동선으로 재구성했습니다.

## P0 통합 검사
- 사용자 저장과 분리된 APPDATA 및 `--p0-tests` 저장 경로를 사용합니다. 실제 GUI는 같은 플래그를 전달해 별도 환경에서 실행했습니다.
- 아래 Git Bash 명령에서 통합 검사 후 두 번째 명령은 새 엔진 프로세스에서 거래 ID·지역·조사 보고·기사 열람 복원을 확인합니다.
```bash
GODOT='godot_console.exe' # PATH에 없으면 설치 위치에 맞게 이 값만 지정
APPDATA="$PWD/.godot/p0_check_appdata" "$GODOT" --headless --path . res://tests/p0_flow_checks.tscn --fixed-fps 60 -- --p0-tests
APPDATA="$PWD/.godot/p0_check_appdata" "$GODOT" --headless --path . res://tests/p0_flow_checks.tscn -- --p0-tests --p0-reload
```
- 정상 결과: `P0_FLOW_OK: failures=0`, `P0_RESTART_OK`. `--fixed-fps 60`은 검사 시뮬레이션을 고정하며 게임의 600초/월 규칙을 변경하지 않습니다.
- 이동 도중 방향키를 누르면 클릭 경로와 건물 접근을 취소합니다. 물/건물 내부 클릭은 가까운 보행 가능 지점으로 보정됩니다. 구버전 저장 위치가 새 충돌 안에 있으면 같은 지도에서 가장 가까운 보행 위치로 옮깁니다.
- 건물 선택 메뉴와 사무실 오브젝트 메뉴에서는 시간을 정지합니다. HUD는 저장 주기와 별도로 0.25초마다 표시를 갱신합니다.
- P0 핵심 기능 구현·통합 검증은 완료했고 사용자 최종 인수는 대기 중입니다. 전체 항목 판정과 자동 검사/실제 GUI 확인의 차이는 DEVELOPMENT_STATUS.md의 최신 P0 점검을 확인하세요.
